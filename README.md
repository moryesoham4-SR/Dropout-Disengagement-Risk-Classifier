# 🎓 Learning Analytics Dashboard for Community Learning Centers
### Dropout & Disengagement Risk Classifier (Community Engagement Project)

Empowering community-based non-formal education centers through data-driven insight and early warning machine learning models.

---

## 📌 Project Overview
Community learning centers provide essential education, remedial tutoring, digital literacy, and continuing education to underserved populations. However, many operate with manual or fragmented records, making it difficult to spot learners who are falling behind or at risk of dropping out.

This project delivers a **Learning Analytics Dashboard** powered by a **Supervised Machine Learning Early Warning System (Model 1)** that ingests field survey data, quantifies disengagement risk, identifies key friction factors, and recommends actionable interventions for center volunteers and coordinators.

---

## 🚀 Key Features

1. **📊 Executive Overview & Educational Analytics**:
   - High-level KPIs: Active attendance rates, percentage of learners reporting skill gains, and total flagged learners.
   - Attendance frequency vs. academic improvement correlations.
   - Device and technology usage breakdowns (smartphones vs laptops/desktops).

2. **🚨 Early Warning & At-Risk Roster (Model 1)**:
   - Filterable student roster categorized into **High Risk**, **Moderate Risk**, and **Low Risk**.
   - Calculated **Early Warning / Dropout Probabilities (0% - 100%)**.
   - Top predictive feature importances generated by the Random Forest classifier.

3. **🧪 What-If Student Risk Simulator**:
   - Interactive intake form to evaluate new student profiles.
   - Outputs instant risk tier classification and recommended volunteer action steps (e.g., 48-hour check-in, peer buddy matching, doubt-clearing sessions).

4. **💡 Learning Challenges & Field Feedback**:
   - Analysis of common roadblocks (study time, understanding concepts, transport, family duties).
   - Direct qualitative suggestions collected from community learners.

5. **📥 Data Exporter & Collection Templates**:
   - Download scored learner datasets.
   - Download standardized blank CSV templates for digitizing subsequent learner cohorts.

---

## 🧠 Machine Learning Model (Model 1)

- **Algorithm**: `Random Forest Classifier` with calibrated heuristic ground-truth scoring and `scikit-learn` pipeline (`StandardScaler` + `OneHotEncoder`).
- **Key Predictor Dimensions**:
  - Attendance frequency & regularity (`Rarely`, `Irregular`, `Sometimes regular`).
  - Reasons for absence (`Lack of interest`, `Family responsibilities`, `Transport`).
  - Classroom engagement & assignment submission habits.
  - Learning difficulties frequency & confidence level.
  - Comfort level approaching teachers for help (scale 1–5).

## 🛠️ Installation & Local Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/moryesoham4-SR/Dropout-Disengagement-Risk-Classifier.git
   cd Dropout-Disengagement-Risk-Classifier
   ```

2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Train the Model (Optional - pre-trained model included)**:
   ```bash
   python train_model1.py
   ```

4. **Run the Streamlit Dashboard**:
   ```bash
   streamlit run app.py
   ```
   Open your browser at `http://localhost:8501`.
